# StoryWeaver

StoryWeaver is a creative writing application powered by Gemini. It helps writers generate, edit, and manage their stories with advanced AI features.

## Features

- **AI Story Generation**: Upload an inspiration image or select a text prompt to have Gemini ghostwrite a captivating opening paragraph in various tones (Suspenseful, Whimsical, Dark, Romantic).
- **Interactive Chat Context**: Co-author stories with an AI writing assistant that remembers your story context and adapts to your prompts.
- **Character Management**: Create and save character profiles with their name, traits, and physical descriptions. Select characters to be automatically injected as context for the AI story generator, keeping the narrative consistent.
- **Focus Mode**: Enter a distraction-free writing environment that hides all non-essential UI elements and side panels.
- **Generative Audio**: Generate custom thematic soundscapes and background music to match your story's tone, or use the Text-to-Speech (TTS) feature to read your story aloud.
- **Local Persistence**: Stories and character profiles are automatically saved locally on your device using a Room database.
- **Dark Mode**: Toggleable dark mode for comfortable writing at any time of day.

## Built With
- Kotlin
- Jetpack Compose
- Gemini Pro API
- Room Database
